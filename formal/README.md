# Formal receipts

Before pushing changes to a model or its hashed sources, record local TLC evidence with `python3 -B formal/check-model.py formal/<model> --record`. Integration PRs run the Linux receipt verifier (`python3 -B formal/verify-receipts.py`), checking input freshness, the TLC pin, passing positive checks and exact-property mutant failures; this checks recorded evidence rather than executing TLC or conformance. Full TLC and conformance still run on main pushes and PRs into main. Open the integration → main PR as a draft at the start of every release. Legacy runners retain their original check scripts, mutation logic and conformance replays through a receipt adapter; `check-model.py --record` runs each complete original gate before recording the same standard receipt.
