# 2.4 automated flow gate

On an occupied development Mac:

```sh
bash scripts/e2e-2.4.sh --swift --report docs.local/E-E2E-SUITE/run.json
```

This runs existing isolated Unix-socket drivers and scoped Swift unit/offscreen
cases. It never launches the native UI runner. Bun loads the repository preload.
The shared 900-second deadline includes child compilation and lock waits.
Use a new report path each time. `PASS_WITH_SKIPS` is distinct from `PASS`.

On the M1 rig, through the lead's admission:

```sh
bash scripts/voicebar-ui-e2e.sh --scenario e2e24 --output "$PWD/.build.noindex/e2e24-native"
```

This reuses the existing QA builder, boundary broker, recorder, supervisor and
exporter. The native scenario has a 900-second budget. Missing sibling fixtures
skip with `pending-lane-A` or `pending-lane-B`; the incomplete ledger fails export.
This is not installed-app or real microphone acceptance.

The native cases are compiled in `E2E24FlowTests.swift`. The intended fixture
contract is `qa-fixture-2.4-<state>`, isolated fixture event sinks, and stable AX
identifiers used in those cases. Lane A/B must reconcile those identifiers with
the lead before native execution. They are an intended contract, not existing
capabilities. The normal `full` native scenario remains available unchanged.

To evaluate release readiness against existing guarded M1 output:

```sh
bash scripts/e2e-2.4.sh --swift --release --native-output /path/to/e2e24-native --report docs.local/E-E2E-SUITE/release.json
```

Release readiness rejects missing/failed native receipts, Swift/Bun failures and
reported skips. The independent installed-candidate, TLC and release promotion
gates still apply. Imported native receipts must be from the candidate under
review, verified by the lead; this script does not establish artifact provenance.

The measured M4 display fixture is `tests/fixtures/e2e-2.4/m4-screen.json`.
Refresh with the read-only `swift scripts/e2e-2.4-screen-probe.swift`, then review
the fixture. It records a 185 pt physical gap, 32 pt safe top and auxiliary display
rectangles. Padding requires an additional 8 pt on each side, 201 pt total.
The fixture sanity test checks the measurement arithmetic, not rendered clearance.

The source-method inventory is `tests/fixtures/e2e-2.4/coverage.json`.
Physical F5 event delivery, actual terminal apps, actual installation/restoration,
recorded mute audio and NarrationLayer transport require separate native/runtime
proof; unit routing and QA fixture sinks cannot establish those claims.
